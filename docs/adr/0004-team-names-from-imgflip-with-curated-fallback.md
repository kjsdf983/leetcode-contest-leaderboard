# Team names generated from Imgflip's live meme templates, with the curated word list as fallback

`generateTeams` sources team names from a live fetch to Imgflip's `get_memes` endpoint, filtered to template names that are two words or fewer after a whitespace split (e.g. "Two Buttons", "Epic Handshake" survive; "Bernie I Am Once Again Asking For Your Support" doesn't), deduplicated. The fetch is wrapped in a 10-second timeout (`AbortController`) and kicked off once when the builder renders, cached in memory for the rest of that session — it is never repeated or retried within the same page load. If it fails, times out, or returns zero names after filtering, team naming falls back to the existing curated `TEAM_WORDS` list unchanged. The two sources are never blended: a given contest's team names come from exactly one or the other, decided once per builder session, not per team.

Because `generateTeams` is called synchronously from input-event handlers (every edit to participants or team size), the fetch isn't awaited inline. Instead, `loadLiveWords` overwrites `TEAM_WORDS` in place, entry by entry, as each fetched template passes the word-count and dedup checks, stopping once every slot has been filled or the fetched list runs out — whichever comes first. `generateTeams` keeps reading `TEAM_WORDS` exactly as before; no separate pool variable or fallback expression was needed. If a team is generated before the fetch settles, or the fetch only fills some of the slots, the untouched slots simply keep their original curated word — a partial mix of live and curated names is an accepted outcome of this approach, not blocked against. No async plumbing was added to the builder's existing input-handling flow.

Each swapped-in name is also recorded in `TEAM_WORD_LINKS` (name → Imgflip's `url` field for that template). `generateTeams` attaches this as an optional `nameUrl` on the returned team object when the chosen name has one. The leaderboard renders a team's name as a link to `nameUrl` when present, and as plain text otherwise — so curated (`TEAM_WORDS`) names stay unlinked, matching their current behavior, while live meme-derived names link out to the template they came from. This adds an optional `nameUrl` field to entries in the `teams` array of the Contest State, alongside the existing `name` and `members` fields.

A wide range of alternatives was evaluated and rejected. Real-world "trending" and "on this day" content — Wikipedia's most-read feed, Wikipedia's on-this-day events, Reddit, GitHub trending, CoinGecko — reliably surfaces real people's names, place names, and current events, which read as topical but not funny, and periodically surfaces political figures, deaths, or other content unsuited to a casual leaderboard; a same-day sample of Wikipedia's most-read feed turned up "Anthony Fauci" and "Lindsey Graham" alongside film and sports trivia, confirming the risk isn't hypothetical. Space-themed live sources — NASA's APOD and NeoWs, Launch Library 2, Open Notify — were technically viable (APOD and Launch Library both extract cleanly into short names) but were dropped in favor of keeping to a single live source plus the curated fallback; NASA's shared `DEMO_KEY` rate limit and exposure to US government shutdowns, and Open Notify's outright unresponsiveness, were additional marks against relying on either. Comedy-native sources — a corporate-buzzword generator, dad jokes, Checkiday's daily wacky holidays, Datamuse's rhyme engine, Urban Dictionary, Giphy, xkcd — were each either too dry, too dependent on a paid key, too narrow a joke register, or too dependent on the joke's full sentence to survive being cut down to one or two words. Imgflip's usage-ranked meme template list was the one source that reliably produced short, recognizable, funny names with no API key and no signup.

## Consequences

- `TEAM_WORDS` is kept, not deleted — it now serves as the offline/failure fallback rather than the only source.
- Team names are still frozen into the Contest State URL exactly as before (see 0001, 0002) — this only changes how the builder picks a name at generation time, not where or how it's persisted.
- No automated tests cover the fetch/timeout/fallback path; verification is manual, via the Network tab and devtools request-blocking.
